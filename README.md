# ДораТехно — контрольная работа №2

Многостраничный адаптивный сайт магазина электронной техники по дисциплине «Фронтенд и бэкенд разработка». 

## Репозиторий

- КР №2: <https://github.com/Dattebayo-EK/kr2-bootstrap-shop>
- Страница сайта: <https://dattebayo-ek.github.io/kr2-bootstrap-shop/>

## Технологии

- HTML5;
- Bootstrap 5.3.8, подключённый локально;
- небольшой слой собственных стилей `css/custom.css`;
- JavaScript без дополнительных библиотек.

Bootstrap отвечает за сетку, адаптивные колонки, карточки, кнопки, формы, таблицы, навигацию, offcanvas-меню, modal, accordion, tabs, badge и alert. Собственные стили задают фирменные цвета, размеры товарных изображений и отдельные декоративные детали.

## Что реализовано

- адаптивная сетка `container`, `row`, `row-cols-*`, `col-*` и gutters;
- единая навигация с полноэкранным по высоте Bootstrap Offcanvas;
- главный каталог с выбором раздела, карточками популярных товаров, фильтром категорий и таблицей сравнения;
- отдельные каталоги смартфонов, наушников и ноутбуков;
- работающие фильтры по цене и характеристикам с отображением количества результатов;
- унифицированные Bootstrap-карточки товаров;
- страницы девяти моделей с характеристиками и комплектацией;
- форма заявки с проверкой обязательных полей;
- Bootstrap Modal быстрого заказа, Accordion, Tabs, Alert и Badge;
- страницы корзины, доставки и контактов;
- адаптивное отображение на телефонах, планшетах и компьютерах.
