# ДораТехно — контрольная работа №2

Многостраничный адаптивный сайт магазина электронной техники по дисциплине «Фронтенд и бэкенд разработка». Проект является отдельной реализацией предметной области первой контрольной работы с использованием Bootstrap 5.

## Репозиторий

- КР №2: <https://github.com/Dattebayo-EK/kr2-bootstrap-shop>
- Основная ветка: `main`
- Публикация на GitHub Pages пока не выполнялась.

## Технологии

- HTML5;
- Bootstrap 5.3.8, подключённый локально;
- небольшой слой собственных стилей `css/custom.css`;
- JavaScript без дополнительных библиотек.

Bootstrap отвечает за сетку, адаптивные колонки, карточки, кнопки, формы, таблицы, навигацию, offcanvas-меню, modal, accordion, tabs, badge и alert. Собственные стили задают фирменные цвета, размеры товарных изображений и отдельные декоративные детали.

## Что реализовано

- адаптивная сетка `container`, `row`, `row-cols-*`, `col-*` и gutters;
- единая навигация с полноэкранным по высоте Bootstrap Offcanvas;
- главный каталог с выбором раздела, карточками популярных товаров, фильтром категорий и таблицей сравнения;
- отдельные каталоги смартфонов, наушников и ноутбуков;
- работающие фильтры по цене и характеристикам с отображением количества результатов;
- унифицированные Bootstrap-карточки товаров;
- страницы девяти моделей с характеристиками и комплектацией;
- форма заявки с проверкой обязательных полей;
- Bootstrap Modal быстрого заказа, Accordion, Tabs, Alert и Badge;
- страницы корзины, доставки и контактов;
- адаптивное отображение на телефонах, планшетах и компьютерах.

## Локальное подключение Bootstrap

На каждой странице сначала подключается Bootstrap, затем собственный файл стилей:

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">
```

Перед закрывающим тегом `body` подключается Bootstrap Bundle, содержащий Popper:

```html
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
```

## Как открыть проект

1. Клонировать репозиторий.
2. Открыть папку проекта в редакторе.
3. Запустить `index.html` через Live Server или открыть файл в браузере.

Установка npm-пакетов и сборка не требуются: Bootstrap, скрипты, стили и изображения находятся внутри проекта.

## Адаптивность

- до `576px` — одна колонка, компактные кнопки и карточки;
- от `768px` — две или три колонки в зависимости от раздела;
- от `992px` — двухколоночные страницы товара и формы;
- от `1200px` — расширенная сетка каталога и фиксируемая панель фильтров.
